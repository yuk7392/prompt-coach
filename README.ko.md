# prompt-coach

[English](README.md) | 한국어

Claude Code 모드(함수 훅 플러그인)입니다. 프롬프트 입력창 위에 버튼을 띄웁니다.

- **빠진 것 묻기** (`q`): 지금까지의 대화와 입력 중인 초안을 읽고, 모델이 작업 전에 물었을 질문을 붙입니다(기본 최대 3개). 질문은 `[Clarify]` 목록 아래에 빈칸과 함께 들어갑니다. 세션의 대화를 그대로 이어 묻기 때문에 세션 모델로 돌고 프롬프트 캐시를 재사용합니다.
- **다듬기** (`r`): 쓰신 사실과 조건은 그대로 두고, ASD-STE100 문체의 단순한 문장(한 문장에 지시 하나, 능동태, 한 대상에 한 용어)으로 다시 씁니다. 답을 채운 `[Clarify]` 항목은 본문 조건으로 녹이고, 빈 질문은 지웁니다. 초안만 보내며 기본 모델은 `haiku`입니다.
- **골격** (`t`): 프롬프트 틀을 넣습니다. 입력창이 비어 있으면 틀만, 쓰던 내용이 있으면 그 뒤에 붙입니다. 설정에서 저장한 골격이 있으면 그것을, 없으면 `templates/default.md`(한국어 화면이면 `default.ko.md`)를 씁니다. 모델 호출이 없습니다.
- **되돌리기** (`u`): 마지막 묻기나 다듬기 전의 초안으로 돌아갑니다. 프롬프트를 보내면 사라집니다.
- **설정** (`s`): 모든 기능을 관리하는 패널을 엽니다(아래). `/coach-settings`로도 열 수 있습니다.

`[Clarify]`에 답이 빈 질문이 남은 채 보내면 첫 Enter는 막히고 알림이 뜹니다. 초안은 입력창에 그대로 남고, 같은 초안으로 다시 Enter를 누르면 보냅니다. 모델 호출이 없습니다.

모델이 일하는 동안 초안을 고치면 결과가 그 위를 덮어쓰지 않습니다.

## 모양

띠와 패널은 앱 테마의 색을 써서 밝은 모드와 어두운 모드를 따라갑니다. Claude Code 데스크톱에서는 앱 자체의(claude.ai) 버튼 모양으로 그리고, 터미널에서는 띠를 한 줄로 둡니다. 단축키는 기본으로 터미널에서만 켜집니다. 데스크톱에서 켜면 버튼 옆에 키 상자가 함께 붙어서, 켤지는 설정에서 고릅니다.

## 설정

모든 기능은 설정 패널의 다섯 탭에서 관리합니다. 고르는 항목은 누르는 즉시 반영됩니다. 글자 칸은 저장(이번 세션 방식은 적용)이나 Enter를 누르면 반영되고, 치는 동안에는 아무것도 바꾸지 않아서 한글 조합이 끊기지 않습니다. 설정은 플러그인 자체 저장소에 남아 모든 세션이 함께 쓰고, 버튼을 누를 때마다 가장 최근에 저장된 값을 씁니다.

| 탭 | 정하는 것 |
|---|---|
| 일반 | 언어(자동, English, 한국어), 띠에 보일 버튼(골격, 빠진 것 묻기, 다듬기, 되돌리기), 단축키(자동: 터미널만, 항상, 끄기), 보내기 전 빈칸 경고, 누를 때마다 토큰 표시, 이번 세션 원하는 방식 |
| 빠진 것 묻기 | 질문 수(1~5), 저장해 두는 스타일. 모델은 대화 캐시를 다시 쓰기 때문에 세션 모델로 고정 |
| 다듬기 | 모델(`haiku`, `sonnet`, `opus`, 세션 모델), effort(`low`~`max`, `haiku`는 쓰지 않음), 저장해 두는 스타일, N자보다 짧은 초안 건너뛰기 |
| 골격 | 줄 고치기(Enter나 저장으로 남김), 줄 추가·삭제, 기본 골격으로 되돌리기 |
| 정보 | 버전, 슬래시 명령, 지시문 파일 위치와 경로 복사, 저장소, 모든 설정 초기화(따로 나오는 확인 버튼으로) |

이번 세션 방식과 저장한 스타일은 사용자의 지시로 들어가되, 초안에 쓴 내용을 바꾸지는 않습니다. 언어를 자동으로 두면 settings.json의 `language`가 한국어일 때 띠가 한국어로, 그 밖에는 영어로 나옵니다. 질문과 다듬은 결과는 늘 초안의 언어를 따릅니다.

두 버튼의 지시문은 `prompts/ask.md`, `prompts/refine.md`에 있고 누를 때마다 새로 읽으므로 고치면 바로 반영됩니다. 플러그인을 업데이트하면 원래대로 돌아갑니다. `ask.md`의 `{{draft}}`와 `{{max}}`에는 초안과 질문 수가, 두 파일의 `{{style}}`에는 원하는 방식이 들어갑니다.

## 띠가 안 보이는 곳

초안을 인자로 받는 슬래시 명령이 있습니다. 결과를 보여 주고 클립보드에 복사합니다.

```
/coach-ask <초안>
/coach-refine <초안>
```

## 설치

이 저장소는 플러그인 마켓플레이스이기도 합니다. Claude Code에서:

```
/plugin marketplace add yuk7392/prompt-coach
/plugin install prompt-coach@prompt-coach
```

업데이트:

```
/plugin marketplace update prompt-coach
/plugin update prompt-coach@prompt-coach
/reload-plugins
```

내려받은 폴더로 바로 써 보려면:

```bash
claude --plugin-dir /path/to/prompt-coach
```

## 쓰는 법

입력창 위 띠의 버튼을 누릅니다. 터미널에서는 ctrl+x tab으로 띠에 들어간 뒤 버튼의 단축키를 눌러도 됩니다.

## 상태

- Claude Code 2.1.286에서 `claude plugin validate`, `tsc`, `claude plugin test .`(`tests/`의 시험, 터미널·데스크톱·VS Code·모바일 화면에 그리기)를 통과했습니다.
- Claude Code 데스크톱에서 띠가 보이고, 다듬기가 입력창을 채웁니다. `hooks/register.tsx`의 `TRACE`를 `true`로 바꾸면 읽기와 채우기 결과가 `trace.log`에 남습니다.
