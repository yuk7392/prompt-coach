# prompt-coach

[English](README.md) | 한국어

Claude Code 모드(함수 훅 플러그인)입니다. 프롬프트 입력창 위에 버튼을 띄웁니다.

- **빠진 것 묻기** (`q`): 지금까지의 대화와 입력 중인 초안을 읽고, 모델이 작업 전에 물었을 질문을 최대 3개 붙입니다. 질문은 `[Clarify]` 목록 아래에 빈칸과 함께 들어갑니다. 세션의 대화를 그대로 이어 묻기 때문에 세션 모델로 돌고 프롬프트 캐시를 재사용합니다.
- **다듬기** (`r`): 쓰신 사실과 조건은 그대로 두고, ASD-STE100 문체의 단순한 문장(한 문장에 지시 하나, 능동태, 한 대상에 한 용어)으로 다시 씁니다. 답을 채운 `[Clarify]` 항목은 본문 조건으로 녹이고, 빈 질문은 지웁니다. 모델은 `refineModel` 설정으로 고릅니다(기본 `haiku`, `sonnet`, `session`).
- **골격** (`t`): `templates/default.md`의 프롬프트 틀을 넣습니다(한국어 화면이면 `default.ko.md`). 입력창이 비어 있으면 틀만, 쓰던 내용이 있으면 그 뒤에 붙입니다. 모델 호출이 없습니다.
- **되돌리기** (`u`): 마지막 묻기나 다듬기 전의 초안으로 돌아갑니다. 프롬프트를 보내면 사라집니다.
- **설정** (`s`): 모든 기능을 관리하는 패널을 엽니다(아래). `/coach-settings`로도 열 수 있습니다.

`[Clarify]`에 답이 빈 질문이 남은 채 보내면 첫 Enter는 막히고 알림이 뜹니다. 초안은 입력창에 그대로 남고, 같은 초안으로 다시 Enter를 누르면 보냅니다. 모델 호출이 없습니다.

모델이 일하는 동안 초안을 고치면 결과가 그 위를 덮어쓰지 않습니다.

## 설정

모든 기능은 설정 패널에서 관리합니다. 고른 값은 플러그인 자체 저장소에 남아 세션을 넘어 유지되고, `plugin.json`의 `userConfig`는 기본값일 뿐입니다.

| 섹션 | 정하는 것 |
|---|---|
| 일반 | 언어(settings.json 따르기, English, 한국어), 누를 때마다 토큰 표시 |
| 이번 세션 | 원하는 방식. 지울 때까지 묻기와 다듬기에 붙고 저장되지 않음 |
| 버튼 | 골격, 빠진 것 묻기, 다듬기, 되돌리기 켜기·끄기 |
| 빠진 것 묻기 | 스타일, 질문 최대 개수(1~5) |
| 다듬기 | 스타일, 모델(`haiku`, `sonnet`, 세션), effort, N자보다 짧은 초안 건너뛰기 |
| 골격 | 줄 고치기·추가·삭제, 기본 골격으로 되돌리기 |
| 보내기 | `[Clarify]` 답이 비었으면 한 번 멈추기 |

패널 맨 아래에 "모두 기본값으로"가 있습니다. 스타일과 이번 세션 방식은 사용자의 지시로 들어가되, 초안에 쓴 내용을 바꾸지는 않습니다.

언어를 settings.json 따르기로 두면, 거기 `language`가 한국어일 때 띠가 한국어로, 그 밖에는 영어로 나옵니다. 질문과 다듬은 결과는 늘 초안의 언어를 따릅니다.

두 버튼의 지시문은 `prompts/ask.md`, `prompts/refine.md`에 있고 누를 때마다 새로 읽으므로 고치면 바로 반영됩니다. `ask.md`의 `{{draft}}`와 `{{max}}`에는 초안과 질문 수가, 두 파일의 `{{style}}`에는 원하는 방식이 들어갑니다.

## 입력창을 직접 그리는 앱

Claude Code 데스크톱은 입력창을 직접 그리기 때문에 띠와 입력창을 바꾸는 버튼이 동작하지 않을 수 있습니다. 대신 초안을 인자로 받는 슬래시 명령이 있습니다. 결과를 보여 주고 클립보드에 복사합니다.

```
/coach-ask <초안>
/coach-refine <초안>
```

## 설치

이 저장소는 플러그인 마켓플레이스이기도 합니다. Claude Code에서:

```
/plugin marketplace add yuk7392/prompt-coach
/plugin install prompt-coach@prompt-coach
```

내려받은 폴더로 바로 써 보려면:

```bash
claude --plugin-dir /path/to/prompt-coach
```

## 쓰는 법

입력창 위 띠를 클릭하거나 ctrl+x tab으로 띠에 들어간 뒤 버튼의 단축키를 누릅니다.

## 상태

- Claude Code 2.1.286에서 `claude plugin validate`와 `tsc`를 통과했습니다.
- 실제 세션에서는 아직 써 보지 않았습니다. 버튼을 처음부터 끝까지 눌러 본 적이 없습니다.
- Claude Code 데스크톱은 입력창을 직접 그리기 때문에 `$.prompt.fill`이 거부될 수 있습니다. 아직 확인 전입니다. `hooks/register.tsx`의 `TRACE`를 `true`로 바꾸면 읽기와 채우기 결과가 `trace.log`에 남습니다.
